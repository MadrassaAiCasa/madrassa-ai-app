# Project Instructions

## Package Management

- **Never install packages without explicit validation** — ask the user to confirm each `npm install` command before running it
- Always explain why each package is needed before installing

## Conception Docs

- **Read `docs/conception/` before working on a feature** — they contain architecture decisions, design patterns, and endpoint contracts that inform how to implement new code.

## TS/US docs:

if the user tells you `doc the code`, after completing a feature, document it in the appropriate folder under `docs/ts_us/` (e.g., `docs/ts_us/login-and-session/TS-1020_msw_setup.md` for MSW setup). Add: short description, file structure, key patterns, and anything a future developer needs to understand or extend it.
