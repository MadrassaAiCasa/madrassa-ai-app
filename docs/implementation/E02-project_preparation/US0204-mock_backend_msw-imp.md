# Mock Backend (MSW) — Implementation

> Conception: [US0204-mock_backend_msw.md](../../conception/E02-project_preparation/US0204-mock_backend_msw.md)
>
> The **generic** MSW base (reusable by any project), organized by Technical Story.
> Feature-specific handlers live with their feature — auth handlers are documented in
> [E03 / US0301 / TS030107](../E03-authentication/US0301-login_and_session-imp.md).

## File Structure (generic)

```
src/mocks/
├── index.ts              → re-exports setup
├── server.ts             → test server (msw/node)
├── setUp.ts              → browser worker setup
├── handlers/
│   ├── browser.ts        → setupWorker for browser
│   ├── index.ts          → merges all feature handlers
│   └── <feature>/        → one folder per feature (added by each feature)
```

---

## TS020401 — Common MSW setup

Shared files set up MSW once for both environments: `server.ts` (`msw/node`) for
tests, `handlers/browser.ts` + `setUp.ts` for the browser worker, and
`handlers/index.ts` merging every feature's handlers.

`src/mocks/setUp.ts` gates the worker behind `VITE_USE_MOCKS`:

```ts
// src/mocks/setUp.ts
async function enableMocking() {
    if (import.meta.env.VITE_USE_MOCKS !== 'true') return;
    await worker.start({ onUnhandledRequest: 'bypass' });
}
```

Called once in `main.tsx` before render:

```ts
// main.tsx
import enableMocking from './mocks/setUp';

async function main() {
    await enableMocking();
    // render app
}

main();
```

> `public/mockServiceWorker.js` is generated by `npx msw init public/`.

## TS020402 — Test wiring

Tests use the Node server (`msw/node`) — no browser worker, no env var (mocks
always active). The setup file starts the server and resets handlers (and any
per-feature stores) between tests:

```ts
// src/test/setupMSW.ts
import { beforeAll, afterAll, afterEach } from 'vitest';
import { server } from '../mocks/server';

beforeAll(() => server.listen());

afterEach(() => {
    server.resetHandlers();
    // each feature resets its own mock store here
});

afterAll(() => server.close());
```

Registered in `vitest.config.ts` via `setupFiles`. `server.resetHandlers()`
between tests prevents handler pollution.

## Adding new feature handlers

1. Create `src/mocks/handlers/<feature>/` folder (its own `index.ts` + endpoint files + store).
2. Register it in `src/mocks/handlers/index.ts`.
3. Add to `src/mocks/server.ts` and `src/mocks/handlers/browser.ts`.
4. Reset its store in the test setup file's `afterEach`.
